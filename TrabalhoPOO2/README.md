# 🎮 Sistema de Gerenciamento de Personagens de RPG em C#

**Disciplina:** Programação Orientada a Objetos  
**Autores:** Thiago Botelho, Davi Xavier, Betim  
**Ano:** 2025

## 📋 Sobre o Projeto

Sistema completo de gerenciamento de personagens de RPG desenvolvido em C# que demonstra os quatro pilares da POO (Abstração, Encapsulamento, Herança e Polimorfismo) e aplica padrões de projeto.

## 🚀 Compilação e Execução

### **Pré-requisitos**
- [.NET SDK 6.0 ou superior](https://dotnet.microsoft.com/download)
- Visual Studio 2022 **OU** Visual Studio Code **OU** qualquer editor com suporte a C#

### **Método 1: Visual Studio (Recomendado)**
1. Abra o arquivo `.sln` no Visual Studio
2. Pressione **F5** para compilar e executar com debug
3. Ou pressione **Ctrl + F5** para executar sem debug

### **Método 2: Linha de Comando**
```bash
# Navegue até a pasta do projeto
cd caminho/do/projeto

# Compilar o projeto
dotnet build

# Executar
dotnet run
